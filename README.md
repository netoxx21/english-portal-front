# English Portal (front-end)

Interface Web do English Portal, um portal de estudo de inglês. Esta primeira fase cobre as telas de **login** e **cadastro**, integradas à [API de autenticação](https://github.com/netoxx21/api-auth)

## Tecnologias

- HTML5
- CSS3 (variáveis CSS, modo escuro automático)
- JavaScript (sem frameworks)

## Como Rodar

1. Clone o repositório
2. Abra a pasta no VS Code e use a extensão **Live Server** no `index.html`
    (ou abra o `index.html` direto no navegador)
